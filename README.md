# RFG: Egy felhasználóbarát ételgenerátor.
Az RFG (Random Food Generator) weboldal egy iskolai projekt keretein belül lett fejlesztve. A feladatunk az volt, hogy csapatokba szerveződve közös munkarévén létrehozzunk egy saját webalkalmazást. A projekt ötletek adottak voltak, de lehetett saját ötletet is megvalósítani. Saját magánéleti tapasztalataink alapján döntöttünk úgy, hogy egy véletlenszerű ételgenerátort készítünk, amely segítséget nyújthat az átlag embereknek, hogy új recepteket és ételötleteket találjanak. <br><br> Disclaimer: Csak a tervezéshez használtunk mesterséges intelligenciát.


## Funkcionalítás:
- Véletlenszerű ételgenerálás
- Recept linkelés
- Az étel részletes leírása
- Lehetőség új ételek hozzáadására

## Követelmények:
- Internetböngésző
- Internetkapcsolat
