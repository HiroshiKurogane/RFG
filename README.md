# RFG: Egy felhasználóbarát ételgenerátor.
Az RFG (Random Food Generator) egy iskolai projekt keretein belül fejlesztett weboldal. A feladatunk az volt, hogy csapatokba szerveződve közös munkarévén létrehozzunk egy saját webalkalmazást. Az ötletek adottak voltak, de lehetőség nyílt egyéni ötletet is megvalósítására is. Saját magánéleti tapasztalataink alapján döntöttünk úgy, hogy egy véletlenszerű ételgenerátort készítünk. A cél egy olyan projekt megtervezése és létrehozása amely segítséget nyújt egy gyakran feltett kérdésre: "Mit egyek/főzzek ma?".

<br><br> **Disclaimer:** Mesterséges inteligencia csak is kizárólag a tervezéshez lett használva.


## Funkcionalítás:
- Véletlenszerű ételgenerálás
- Recept linkelés
- Az étel részletes leírása
- Lehetőség új ételek hozzáadására

## Követelmények:
- Internetböngésző
- Internetkapcsolat
